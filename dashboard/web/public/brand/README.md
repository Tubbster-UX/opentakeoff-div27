# Brand files

The header and About dialog load these two files by name:

- `Logo Transparent Black@2x.png` (shown on the light theme)
- `Logo Transparent White@2x.png` (shown on the dark theme)

**The files here now are generated placeholders** (a boxed "BRINK DESIGN / PLACEHOLDER" mark), not the real logo.
The real files are in the owner's Google Drive, folder "Brink Design". To use them, overwrite these two files
with the Drive originals, keeping the names, and rebuild. Nothing else needs to change.
